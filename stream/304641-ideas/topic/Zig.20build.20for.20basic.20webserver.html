notramo (Sep 29 2026 at 07:45):

That sense makes to me. I wonder zig build buys anything in coordination, even if just to match the roc compiler build. I thought heard it was designed to be a good build tool even for non zig code, but I don't have actual experience in that.

Non-Zig code usually means C and C++, since Zig can compile these itself, without external tools (zig cc). And Zig has builtin caching for C and C++ compilation, which gcc/clang does not have. So a Zig build system brings much benefit for building C projects. However, for Roc, the Zig build system would still need to call an external compiler (roc), which uses its own caching, so there's not much benefit to using it.
