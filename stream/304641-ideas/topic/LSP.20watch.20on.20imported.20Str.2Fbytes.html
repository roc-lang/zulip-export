Topic: LSP watch on imported Str/bytes

Dan G Knutson (Oct 12 2026 at 15:34):

I noticed that the LSP doesn't live-update if you make changes to an imported non-Roc file. For example, if I've got something (for an Advent of Code problem) like:

import "./input.txt" as puzzle_input : Str

Ok(parsed_input) =
    puzzle_input.trim().split_on("\n")
        .map_try(U64.from_str)

and then I edit input.txt to make it fail to parse, then the LSP only notices the change if I restart the LSP. The same goes for if the LSP was started when parsing was failing and then an edit to input.txt fixes the problem.

For advent of code, this is kind of silly (an error means the parsing is wrong). But in the long term, I'd like to handle assets in games like this, so it'd be really useful to have the LSP watch imported non-Roc files. Is this an appropriate GitHub issue?
