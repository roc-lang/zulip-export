I would like to do Advent of Code with Roc again this year.

I plan to use the built-in echo platform. I really like the idea that all the code for a single day is contained in one file.

A template could look like this:

template file

import "day00.input" as puzzle_input : Str

main! = |args| {
    result = match parse_args(args) {
        Part1 => day1(puzzle_input)?
        Part2 => day2(puzzle_input)?
        Both => {
            "day1: ${day1(puzzle_input)?}\n\nday2:${day2(puzzle_input)?}"
        }
        Help(message) => message
    }
    echo!("${result}\n")
    Ok({})
}

day1 = |_input| {
    Ok("day1 - TODO")
}

day2 = |_input| {
    Ok("day2 - TODO")
}

example_input =
    \\Example Input

    got == example_input
}

Luke Boswell (Nov 23 2026 at 10:24):

Roc has a default or builtin platform that is very simple and has only a single effect, echo! which prints to stdout. It's available without a URL to download or reference a platform -- like a platform-less (or even headerless if you want) app.
