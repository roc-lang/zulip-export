Anton (Sep 05 2026 at 12:00):

Hi @MagicMan,

When the compiler does not have any constraints on a number it defaults to the number type Dec.
So I would use:

unsorted_4 : List(U64)
unsorted_4 = [2, 4, 1, 3]

or

unsorted_4 = [2.U64, 4, 1, 3]
