I also got it working again in nvim with this config (using lazy):

  {
    "neovim/nvim-lspconfig",
    opts = {
      servers = {
        roc = {
          cmd = { "roc", "experimental-lsp" },
          filetypes = { "roc" },
          init_options = {
            trustedWorkspace = true,
          },
          mason = false,
        },
      },
    },
  }

CVE review behind Roc issue #11902

Issue #11902 (https://github.com/roc-lang/roc/issues/11902) came from reviewing CVE-2026-34060, a Ruby LSP code-injection vulnerability (https://github.com/Shopify/ruby-lsp/security/advisories/GHSA-c4r5-fxqw-vh93). Ruby LSP inserted a workspace-controlled setting into a generated Gemfile, allowing a malicious project to execute code when opened in an editor.

The review identified a related trust concern in Roc: opening a file triggered dependency downloads and native compile-time evaluation without an explicit workspace-trust opt-in.

Roc did not share Ruby LSP’s injection defect. The review classified the concern as “weakness possible”, since escaping Roc’s effect-free compile-time evaluation would require an additional compiler or runtime bug.
