Topic: official vscode extension

Anton (Nov 05 2026 at 09:47):

We have created an official vscode extension for Roc to make sure vscode users can have the most up-to-date experience.

You may get a warning that the publisher is not verified, I have performed all verification steps I can do on my end, the remaining work needs to be done by someone at Microsoft.

Big thanks to @Luke Boswell whose fork inspired vital components, and to the maintainers of other Roc vscode extensions @Ivan Demchenko, @Benjamin Thomas and @Hannes for their efforts :heart:

Here are the features:

  • Syntax highlighting, including Roc code blocks in doc comments and Markdown files
  • Diagnostics as you type
  • Formatting (format on save is on by default for Roc files)
  • Hover with inferred types, go to definition, find references, document highlights
  • Completion, rename, document symbols, folding and selection ranges
  • Inlay hints for inferred types
  • Code action: annotate a binding with its inferred type
  • Semantic highlighting
  • Roc: Run File and Roc: Test File from the editor title bar, and a roc task type
