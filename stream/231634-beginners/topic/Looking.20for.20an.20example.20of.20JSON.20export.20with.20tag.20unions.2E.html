Stuart Hungerford (Nov 27 2026 at 04:14):

FWIW I ended up adding a record type to each shape module suitable for JSON or other export then the to_json() function can become:

to_json : Polyline -> Try(Str, _)
to_json = |shape| {
  Json.to_str_try(Polyline(shape.to_record()))
}
