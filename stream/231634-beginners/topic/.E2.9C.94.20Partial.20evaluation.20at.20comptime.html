add = |a, b| (a * 5) + b

add(1, getUserInput()?)

Richard Feldman (Oct 18 2026 at 18:48):

runtime, and it would still be comptime if add were curried...but you could get it to be comptime if you separated the arithmetic expressions like so: 

add = |a| {
    captured = a * 5
    |b| captured + b
}
