Topic: declarations that reference mutable variables

MorganEarlJones (Nov 13 2026 at 16:15):

Should non-effectful declarations be allowed to reference mutable variables? In the following code, the non-effectful value 'x' is defined as the most recent value of the mutable variable $y:

main! = |_args| {
var $x = "boop"
$x = "beep"
y = $x
$x = "boop"
echo!(y)
Ok({})
}

Wouldn't it be preferable to force some notation on y as with effectful functions?
i.e., y! = $x, or perhaps y$ = $x, to make explicit that the value assigned is dependent on the immediate value of a mutable variable.
