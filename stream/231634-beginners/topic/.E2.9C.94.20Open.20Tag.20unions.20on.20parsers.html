Anton (Nov 21 2026 at 18:24):

Only function definitions can generalize. Non-function values have exactly one type and annotations can only make the type stricter, not more flexible.

You can however use _ like this:

parse_left : Parser(List(U8), _, _)
parse_left = Parser.const(|n| Left(n)).skip(Parser.Utf8.codeunit('L')).keep(Parser.Utf8.digits({}))

parse_right : Parser(List(U8), _, _)
parse_right = Parser.const(|n| Right(n)).skip(Parser.Utf8.codeunit('R')).keep(Parser.Utf8.digits({}))

Or, define the union once and use it everywhere:

Either : [Left(U64), Right(U64)]

parse_line : Parser(List(U8), Either, _)
parse_left : Parser(List(U8), Either, _)
parse_right : Parser(List(U8), Either, _)
