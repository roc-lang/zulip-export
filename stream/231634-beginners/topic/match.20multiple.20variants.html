specifically, this:

            Header(a), Header(b) => a.is_eq(b)
            Data (a), Data(b) => a.is_eq(b)

...needs to be this:

            (Header(a), Header(b)) => a.is_eq(b)
            (Data (a), Data(b)) => a.is_eq(b)
