Stuart Hungerford (Nov 22 2026 at 03:23):

I've only just started reading the Roc documentation and it seems like a really humane and well thought out language--great work!

I was wondering if this syntax ...}.{... as used in the following code can be split into separate declarations or sections. It's probably just me but I find the "." character is doing a lot of conceptual work in linking the {} sections.

Apologies if this is answered in the docs I haven't gotten to yet.

Builder(a) := { value : a }.{
    pure : a -> Builder(a)
    pure = |x| { value: x }

    map2 : Builder(a), Builder(b), (a, b -> c) -> Builder(c)
    map2 = |a, b, combine| { value: combine(a.value, b.value) }

    run : Builder(a) -> a
    run = |builder| builder.value
}

record_builder = || {
    built = {
        count: Builder.pure(42.U64),
        name: Builder.pure("Roc"),
    }.Builder
    # The two-field builder above calls Builder.map2 with a function that makes the record.
    built.run()
}

I think trying to do

A := {fields}.{funcs}

Is not going to work.

You can put private helpers out side this class def, but yeah that's not really what you ask for.

Technically you can do 

A := {}
.{}

But fmt will immediately put them back and nuke the \n.

Dan G Knutson (Nov 22 2026 at 15:51):

re: the original question, when hand-writing Roc, I like to throw a comma after the fields so the formatter does this:

Builder(a) := {
    value : a,
}.{
    pure : a -> Builder(a)
    pure = |x| { value: x }
