So I have a workaround but it feels kind of clunky.
I've had to match each return explicitly.

            Function(fn) =>
                match fn(args) {
                    Ok(r) => Ok((r, env))
                    Err(WrongArity) => Err(WrongArity)
                    Err(TypeMismatch) => Err(TypeMismatch)
                    Err(EmptyList) => Err(EmptyList)
                    Err(OutOfRange) => Err(OutOfRange)
                }
