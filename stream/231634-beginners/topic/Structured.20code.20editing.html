Dan G Knutson (Nov 06 2026 at 19:21):

I think some of the features originally planned for editor plugins are still useful in a world where you assume direct code editing is way less common. In particular:

  1. Having higher-level editing options (similar to LSP code actions, but maybe more ambitious) is useful for an agent as well as a human. An LSP-like compiler API can offer things like code search tools to agents and humans, for example.
  2. In a world where most people are generating most code via LLMs, I think editor plugins for stuff like visually editing constants (like a color picker plugin) or inspecting unit test execution are still useful as tools for understanding generated code.

Basically, things that would have been useful without LLMs for understanding or interacting with a large codebase someone else wrote are now useful for everyone.
