Jared Ramirez (Oct 06 2026 at 12:47):

yup, this is a known issue! currently polarity does not apply to host functions return types (ie returned tag unions are not implicitly opened), because the host ABI contract requires a closed union exactly

to fix, i believe we will need to implement an implicit remapping when you use a host function like this, along the lines of an implicit match to instantiate it as open

The platform requires  main!  to have a specific type.

main! = |_args| {
        ^^^^^^^

Here it has the type:

    List(Str) => Try({}, [StdoutErr(Str)])

But the platform requires:

    List(Str) => Try({}, [Exit(I32)])
The requirement is declared here:

requires {} { main! : List(Str) => Try({}, [Exit(I32), ..]) }
              ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
