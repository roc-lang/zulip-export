Richard Feldman said:

how do other languages do this?

Apparently different languages have different solutions:

  • C/C++: x == 0.0 && signbit(x)
    • Rust, C#, Go, Julia: similar to C/C++.
  • JS/TS: Object.is(x, -0)
  • Haskell: isNegativeZero x
  • Swift: x.floatingPointClass == .negativeZero or x.isZero && x.sign == .minus
  • Kotlin: x.equals(-0.0)
  • Python: x == 0.0 and math.copysign(1.0, x) == -1.0
  • Ruby: x == 0.0 && (1.0 / x) == -Float::INFINITY
