Topic: How to see values from failing top-level `expect` statements

Daniel (Nov 06 2026 at 18:20):

The language reference says this about top level expect:

When one fails, the report shows the failing expression, along with the values of any top-level names it referenced.

I get output telling me which excpect test failed, but it doesn't show me any debug representation of the values it failed with. For example:

double = |n| n * 2
# failing test
expect double(21) == 43

The output just shows me that line, but it doesn't say what the value of double(21) In other languages, I would expect to see something like 42 == 43, so I can see _why_ my test is failing.

I can sort of get around it by writing tests like so, but this feels pretty tedious:

expect {
    got = norm("../../A/B")
    res = got == "../../A/B"
    if !res {
        dbg got
    }
    res
}

Is there a better way, or perhaps I am missing something? Or is this just a known limitation of the expect statement?

Anton (Nov 06 2026 at 18:49):

Hi @Daniel,
The docs are indeed incorrect, the nice version of this feature is planned for after 0.1. I will correct the docs.

You can improve the workaround like this:

expect {
    got = norm("../../A/B")
    dbg got
    got == "../../A/B"
}

Daniel (Nov 06 2026 at 19:01):

Ah, another question. I noticed that expect requires the expression to be pure. Is there any way to test effectful functions?

Anton (Nov 06 2026 at 19:08):

Yes, you can :)
This should do it:

check = |received, expected| {
    ok = received == expected
    if !ok {
        dbg { expected, received }
    }
    ok
}
