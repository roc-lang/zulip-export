Anton (Oct 20 2026 at 10:18):

Hi @Albert,
This is a use case Roc is designed for but we don't have a guide for this yet. It should be doable with AI assistance. On maturity, there are still frequent breaking changes in Roc, we do hope to release Roc 0.1 soon.

Now, rather than embedding the compiler, I’d define your plugin API as a Roc platform whose targets use output: Shared. The host is then just a small Rust staticlib that forwards hosted functions to your editor. Your editor ships the roc binary, runs roc build plugin.roc to get a .dylib/.so/.dll, and dlopens it. See test/dylib in the roc repo and roc-platform-template-rust / basic-cli for Rust hosts, and use roc glue with RustGlue.roc for bindings. There’s no stable embeddable compiler library (libroc) yet; that’s planned for after 0.1.
