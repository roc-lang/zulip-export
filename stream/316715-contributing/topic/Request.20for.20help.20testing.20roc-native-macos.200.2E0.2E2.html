I've been cooking a new platform for native macOS apps and would love any help from people testing it. Packaging everything up for a platform release and getting that working reliably across every machine can be finicky but I think I've got something working nicely now.

curl -LO https://github.com/lukewilliamboswell/roc-native-macos/releases/download/0.0.2/macos.roc
roc macos.roc init my-app
cd my-app
roc macos.roc run

That should start up the starter template app.
