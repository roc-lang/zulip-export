from Claude:

I changed the declaration in lib/Point.roc itself, and every import stayed as it was:

roc
import lib.Point # unchanged in every caller
...
corner : Point # was Point.Point
corner = Point.at(3.0, 4.0)

The old module wrapped an empty type (Point :: [].{ Point : { x, y } }), so the record type was nested one level down as Point.Point. Now the module's own type is the record (Point := { x : Pixels, y : Pixels }.{ … }), so after a plain import lib.Point, the name Point is both the type and the home of Point.at. That's the same pattern as Cat, Conifer and Distance. The rename touched 41 files, and all 59 apps check clean.

An import lib.Point as P alias would only shorten the module name, and the doubled name would still be there.
