Aurélien Geron (Oct 30 2026 at 02:10):

Yes, it would be nice if the doc for every function and type started with a short sentence that could be used as a snippet. :+1: Python imposes that, we could reuse the same rules. ChatGPT says:

  • Keep the first sentence under 72 characters: While general code lines can extend to 79 characters, PEP 8 specifically restricts flowing text blocks like docstrings and comments to a maximum of 72 characters.

  • Write as an imperative command: The summary should prescribe the function's effect as an action ("Do this", "Return that"). For example, use "Return the absolute value" rather than "Returns the absolute value".

  • End with a period: The summary line should always end with a period.

  • Isolate with a blank line: If you are writing a multi-line docstring, that first summary line must be separated from the rest of the deeper explanation by exactly one blank line.
