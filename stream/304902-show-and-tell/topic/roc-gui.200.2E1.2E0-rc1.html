Luke Boswell (Oct 24 2026 at 09:23):

It's a bit rough and I've been sitting on this for a while poking at bugs elsewhere -- but with all the fixes that landed recently I've managed to get a release out for testing roc-gui.

https://github.com/lukewilliamboswell/roc-gui/releases/tag/0.1.0-rc1

Check it out and let me know if you have any issues running on your system. The vast majority of my time has been setting up infrastructure and packaging gpui so it should just work out of the box on everyone's system -- the flip side is the API is probably less than ideal. I've had quite a few attempts at Richard's Action-State design over the years, and this is by far the nicest and the performance seems great too.

I haven't updated the gpui pin into the zed repo for a little while so it's a bit behind, and there's quite a few bugs to fix. Updating that is non-trivial when it comes to getting it working across all the different targets, and providing all the linker inputs like macOS and Windows stubs etc.

GUI platform's are enormous and very complex, and I have a lot of respect for those giants who have made gpui so nice that we can build on top of it.

Looking forward to see what people build with this :grinning_face_with_smiling_eyes:
