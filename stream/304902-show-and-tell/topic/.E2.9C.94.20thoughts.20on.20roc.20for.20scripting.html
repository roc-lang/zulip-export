Luke Boswell (Nov 20 2026 at 00:53):

I found the issue I think. I suspect your restriced-roc platform's allocator is unwinding the stack from Zig's SafeAllocator, in dev mode Roc's allocator caller is in shared-memory mapped outside Zig's known ELF modules so apparently this causes Zig to clear the cache and rescan modules. This script is allocating and freeing many heap allocated strings so this stacks up exponentially.

If I build the host in Debug mode I see 99.9% of the cycles in SafeAllocator.captureStackTrace

Luke Boswell (Nov 20 2026 at 00:54):

Building the host in ReleaseFast drops it from 11,600ms down to 120ms
