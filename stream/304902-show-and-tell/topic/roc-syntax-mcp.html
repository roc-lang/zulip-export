Hi all! I would like to present the MCP server I was working on to teach LLMs to write Roc effectively. It serves language reference including idioms and topics like scripting, knowledge about common platforms and packages, and tools like Hoogle-style search over built-in, platform and project functions, and roc_check of files and snippets! It recognizes what platform you are working on to provide only relevant results, and has a third-party plugin system for more platforms and packages.

It is NPM based, install with npm i -g roc-syntax-mcp. Plugins are also NPM packages - to add, run roc-syntax-mcp plugin add @roc-syntax/roc-ray @roc-syntax/joy

Today all built-in corpus and first-party plugins are updated to latest Roc and package releases, which include:
bundled

  • basic-cli
  • basic-webserver
  • roc-parser
  • roc-random
  • http

first-party plugins

  • @roc-syntax/roc-ray
  • @roc-syntax/joy
  • @roc-syntax/weaver

I hope the server is helpful, and will get better over time with community feedback
I very much can't cover nuance of every platform and package, so any contributions from package maintainers are invaluable :slight_smile:
