Roux

Roux is a web platform for Roc that includes everything you need to deploy.

  • A database that checks your queries. SQLite comes built in, and a query that doesn't match your schema is a compile error.
  • Templates with editor support. Typed HTML templates in Roc + mustache, with syntax highlighting in Zed.
  • Live updates. Push changes to the browser with server-sent events (SSE)
  • HTTPS on its own. It gets and renews its own certificate.
  • Live reload. Save a template and roux has it rebuilt in 815 µs:

Fast, and raced every night against Go, Rust's axum, and basic-webserver. Rendering a template, roux serves about 1.9× axum's requests and 7.5× Go's, within 6% of fourneau, the raw Zig server it's built on:

Over TLS it serves 168,700 requests/s, to axum's 80,700.
The latest results: https://fourneau.y2kbugger.com/

Try it in a minute. The tutorial is itself a roux app, and that live reload timing is its first page: https://github.com/Eldhus/roux-tutor
