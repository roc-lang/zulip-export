Luke Boswell (Nov 22 2026 at 21:07):

I have been thinking about how the reactive engine for roc-signals will translate across to any reactive UI, and so I thought I'd give native Android development a try to pilot the concept. I'm not a mobile developer, I haven't done more than a few hello world tutorials over the years... but I had a clear idea of the Roc platform side constraints and how I wanted this to work -- so I delegated a lot to Opus 5.5

https://github.com/lukewilliamboswell/roc-native-android

There is a companion cli tool which scaffolds out a basic project and help manage packaging into an APK etc.

If people find this useful, I'd be open to extending and improving it. If anyone takes this and makes a better native platform for mobile development I'll be stoked.
