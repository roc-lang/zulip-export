I'd like to present Pi Spigot in Roc, compiled to 6502 instruction set, running on a emulator written in pure SQL statements. You might be asking yourself "is this a joke or is it real?" Well, yes it is a joke, but it is also real, and it was really done completely while I was at the gym this morning.

https://github.com/y2kbugger/roc-on-6502

rocpispigot.webm

How it works

apps/pi.roc ──roc──▶ LLVM bitcode (wasm32) ──retarget──▶ 6502 IR
            ──llvm-mos clang + platform/host.c──▶ 5 KB 6502 image
            ──mksql.py──▶ pi.sql ──sqlite3──▶ π

I have also commited the build output pi.sql, so you can just run the sql without needing the build chain:

sqlite3 < pi.sql

My favorite part is that loading the rom is just inserting into the memory table.

Oh and yes, this is also a unikernel design, I couldn't seem to fit linux.

The 6502 sql cpu is based on my previous work https://blog.y2kbugger.com/lc3-sql.html, which was, ahem, started in the pre-LLM days.
