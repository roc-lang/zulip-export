Hannes (Sep 04 2026 at 15:35):

Here's a small example program:

app [main!] {
    cli: platform "https://github.com/roc-lang/basic-cli/releases/download/0.21.0/4rAQg8kUYZ3Vksr4qMQHpaFYNiHSn9GgS7gVxghd1XYV.tar.zst",
    ascii: "https://github.com/Hasnep/roc-ascii/releases/download/v0.5.0/5WxqRf15XVko4HxVq5dW8r84s95CxrtvzrjZYwbg9Z3H.tar.zst",
}

import cli.Stdout
import cli.Stderr
import cli.Stdin
import ascii.Ascii

repeat_input_but_shouting! = || {
    stdin = Stdin.read_to_end!().map_err(|_| "Failed to read from stdin!")?
    msg = Ascii.from_ascii_bytes(stdin).map_err(|_| "Non-ASCII input data!")?
    Stdout.write!(msg.to_uppercase().to_str()).map_err(|_| "Failed to write to stdout!")
}

main! = |_| {
    match repeat_input_but_shouting!() {
        Ok(_) => Ok({})
        Err(err_msg) => {
            _ = Stderr.line!(err_msg)
            Err(Exit(1))
        }
    }
}

Before I realized/remembered that https://github.com/Hasnep/roc-ascii was a thing, I had Claude writing some code, and the same needs came up: is_digit, is_hex_digit, is_alphanumeric, is_whitespace, is_punctuation, is_control, is_letter, to_lowercase, to_uppercase are all in my codebase.

Steve Howell (Oct 29 2026 at 16:46):

FWIW there's much design work to do to move https://github.com/showell/roc-webbox/blob/a182bf2/chat/Ascii.roc into builtins soon after 0.1.0.

It's 227 lines of code, mostly tests. The tests are completely exhaustive. The APIs were all cross-checked against Zig, Rust, C, and Go to try to conform to de facto standards. Every single function is implemented with a one-liner.

I had Claude look into calling directly into zig, but the Roc versions pretty much produce the same code as zig. The zig standard library doesn't do anything exotic like lookup tables that we would want to investigate.

Here's a quick taste:

    ## `a`-`z` to `A`-`Z`; every other byte, 128 to 255 included, unchanged.
    ## Zig `toUpper`, Rust `to_ascii_uppercase`, C `toupper`, and the per-byte
    ## rule of `Str.with_ascii_uppercased`.
    to_uppercase : U8 -> U8
    to_uppercase = |c| if c >= 'a' and c <= 'z' c.bitwise_xor(0x20) else c
