Most of the time it's best to support UTF-8, but sometimes you have data that is just ASCII and you can avoid some of the complexity of UTF-8, so I made a quick package with two types: an ASCII string and an ASCII character. See the docs for more info: https://hasnep.github.io/roc-ascii

Hannes (Sep 04 2026 at 15:35):

Here's a small example program:

app [main!] {
    cli: platform "https://github.com/roc-lang/basic-cli/releases/download/0.21.0/4rAQg8kUYZ3Vksr4qMQHpaFYNiHSn9GgS7gVxghd1XYV.tar.zst",
    ascii: "https://github.com/Hasnep/roc-ascii/releases/download/v0.5.0/5WxqRf15XVko4HxVq5dW8r84s95CxrtvzrjZYwbg9Z3H.tar.zst",
}

import cli.Stdout
import cli.Stderr
import cli.Stdin
import ascii.Ascii

repeat_input_but_shouting! = || {
    stdin = Stdin.read_to_end!().map_err(|_| "Failed to read from stdin!")?
    msg = Ascii.from_ascii_bytes(stdin).map_err(|_| "Non-ASCII input data!")?
    Stdout.write!(msg.to_uppercase().to_str()).map_err(|_| "Failed to write to stdout!")
}

main! = |_| {
    match repeat_input_but_shouting!() {
        Ok(_) => Ok({})
        Err(err_msg) => {
            _ = Stderr.line!(err_msg)
            Err(Exit(1))
        }
    }
}
