In order to solidify the theorem in my brain, I devised a little language called Nibble that in the same spirit as a Turing machine but with everything finite. It has four opcodes:

  • nada - does nothing
  • zero - accepts 0
  • decr - rejects 0, decrements 1, 2, and 3
  • mod2 - turns 2 into 0 and 3 into 1

Steve Howell (Nov 25 2026 at 23:26):

Every Nibble program has to be exactly six instructions. You feed it a value of 0, 1, 2, or 3, and there are three possible outcomes:

  • zero accepts when AX=0
  • decr rejects when AX=0
  • the program runs to completion and implicitly rejects the number

AX was the single register of the machine implemented in Python.

Steve Howell (Nov 26 2026 at 11:41):

The great thing about Nibble is that it's a completely understood language, because you can literally run every possible Nibble program and tabulate results. A Nibble program is six instructions over four opcodes, so 12 bits. 2 ^ 12 is 4096. So there are only 4096 programs, period. The AX register is two bits representing 0, 1, 2, or 3. There are only 2 ^ 4, or 16, languages over {0, 1, 2, 3).

Steve Howell (Nov 26 2026 at 12:42):

from Claude:

The Nibble VM can be described as a mathematical object in three ways, depending on which bits you treat as inputs.

  1. Running a program is a Boolean function of 14 bits. The input is two bits (AX = 0 to 3), the program is twelve (six instructions, two bits each), and the output is accept or reject: f : {0,1}^14 → {0,1}. That's 2^14 = 16,384 points, one big truth table.

  2. Each program decides exactly one problem. Run a program on all four inputs and the four verdicts are one of the 16 subsets of {0, 1, 2, 3}. That's a function g from the 4,096 programs onto the 16 problems. It's a surjection, since every problem has a program. The programs that land on one problem form its fiber: 883 programs decide {0, 2}, and only program 1689 decides {0, 2, 3}.

  3. "Does this program decide this problem?" is a function of 16 bits. Add the problem's four bits to the program's twelve: V : {0,1}^16 → {0,1}. V is the characteristic function of a relation, the graph of g, so exactly 4,096 of its 65,536 points are 1. You can also call V a verifier: hand it a problem and a candidate program, and it checks the candidate by running it four times.

All of this is plain Boolean algebra: AND, OR and NOT on bits.

Steve Howell (Nov 26 2026 at 12:47):

And Roc finally makes its first appearance! (many more to come) What better language than Roc to express that view 1 is simply a pure function?

## The Nibble machine as one function, f : {0,1}^14 -> {0,1}. The 14 bits
## are a number below 2^14: the top 2 bits are the input, where AX starts,
## and the low 12 are the program, six lines of two bits, line 1 the highest
## pair (nada 00, zero 01, decr 10, mod2 11). So the program's 12 bits read
## as its number: 1689 is zero, decr, decr, zero, decr, zero.
Fourteen :: [].{

        ## Where a run stands: still going, with AX, or done.
        Run : [Going(U64), Accepted, Rejected]

        ## One line: `zero` accepts at 0, `decr` rejects at 0 or takes 1 from AX,
        ## `mod2` keeps AX's low bit, `nada` does nothing. A run that is done
        ## stays done.
        step : Fourteen.Run, U64 -> Fourteen.Run
        step = |run, op|
                match run {
                        Going(ax) =>
                                if (op == 1 and ax == 0) Accepted
                                else if (op == 2 and ax == 0) Rejected
                                else if (op == 2) Going(ax - 1)
                                else if (op == 3) Going(ax % 2)
                                else run
                        Accepted | Rejected => run
                }

        ## f itself: true when the program accepts the input. A run that gets
        ## past line 6 still going rejects.
        f : U64 -> Bool
        f = |bits| {
                input = bits // 4096
                program = bits % 4096
                # Each line's two bits, line 1 first: 4^5, 4^4, ... 4^0.
                places = [1024, 256, 64, 16, 4, 1]
                places.fold(Going(input), |run, place| Fourteen.step(run, (program // place) % 4)) == Accepted
        }

        ## The problem a program decides: the inputs f accepts.
        decided : U64 -> List(U64)
        decided = |program| [0, 1, 2, 3].keep_if(|input| Fourteen.f(input * 4096 + program))
}

# Program 1689 is the one program that decides {0, 2, 3}.
expect Fourteen.decided(1689) == [0, 2, 3]
# Program 2704 (decr, decr, decr, zero, nada, nada) decides {3}.
expect Fourteen.decided(2704) == [3]
# Programs 0 (all nada) and 4095 (all mod2) decide { }.
expect Fourteen.decided(0) == []
expect Fourteen.decided(4095) == []
# f is 1 at 5,596 of its 16,384 points, as the C's cross-check counts.
expect List.from_iter(U64.until(0, 16384)).keep_if(Fourteen.f).len() == 5596

Steve Howell (Nov 26 2026 at 22:17):

One quirk of nibble is that the nada instruction literally does nothing. It has two reasons to exist:

  • with 2 bits for the opcode, it's painless (and actually smart) to add nada as the fourth instruction (00=nada, 01=zero, 10=decr, 11=mod2)
  • it gives you a way to "pad out" programs to six instructions, so that every program is exactly six instructions (and there are exactly 2^12=4096 possible programs), which makes some of the math just easier

Here is an easy program that accepts the language {0}:

zero
nada
nada
nada
nada
nada

It has the instructions encoded as 01 00 00 00 00 00.

Steve Howell (Nov 26 2026 at 22:20):

So one of the challenges of Nibble is to write the shortest program after stripping the nada padding. The brute force way to do this is to try out all 4096 programs and just pick the smallest program that works on the desired language ({0}). And that's kinda what we do! We actually use rocsat as an oracle for this.

Steve Howell (Nov 26 2026 at 22:23):

In order to make this more challenging for us (and for rocsat) is that we created Nibble++ today. Nibble++ takes in a four-bit register instead of a two-bit register. So the single inputs range from 0 to 15 and the number of languages is 2**16. We replaced nada with half and no longer cap the instructions to six.

Steve Howell (Nov 26 2026 at 22:24):

That's about as far as you can and still brute-force a lot of stuff. Even 2 ** (2 ** 5) gets ugly real quick, so 5-bit inputs are not in the plan.

Steve Howell (Nov 26 2026 at 22:35):

In Nibble++, evaluating a program's behavior on a single input is polynomial time. Trying to find the shortest Nibble++ program that respects a certain language (say {5, 7, 8, 9, 12}) is exponential and probably difficult for most humans! But SAT solvers can do just this.
