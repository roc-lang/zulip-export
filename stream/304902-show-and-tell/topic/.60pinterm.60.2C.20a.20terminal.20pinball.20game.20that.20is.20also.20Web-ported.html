Here's what I meant by digital vs analog.
1) Compute 2 + 2 => digital. It's strict.
2) Detect cat on a picture => analog. There's a complex continuous space of cat pictures, the border is fuzzy.

Until recently programming languages were digital-only. Since neural nets came along, we can now express more "analog" things. Aurélien Geron (Oct 12 2026 at 04:32):

Several common use cases for macros are covered by compile-time evaluation: parsing/validating static string literals, precomputed lookup tables (e.g., CRC tables), compile-time string hashing, and a couple more.

We're mostly missing some automatic boilerplate derivation (like Rust's #[derive(...)]), some syntactic sugar, AST-level diagnostics & reflection (e.g., assert_eq!(a, b)). So far, the last one is the only one I've missed, but it's no longer needed now that the expect statement prints more diagnostics.

Macros also obfuscate the code, and mess with editors.
