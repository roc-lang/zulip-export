Steve Howell (Nov 18 2026 at 19:12):

This is my recommendation for Richard Feldman to possibly write in the blog:

Roc has three independently written roc markdown processors that are probably sufficient for most people's needs:

  • Karl's version (grayrest/roc-markdown) strives toward 100% standards compliance and speed.
  • Steve Howell's version (showell/roc-markdown) focuses on speed and special extensions/modifications for chat and writing online books.
  • Luke Boswell's version lives in a general purpose library for parsing (roc-parser)

All three are currently used in production.

Steve Howell (Nov 18 2026 at 19:19):

As an aside, I have been working on porting my zig-based chat program to be mostly Roc. Some of the distinctive pieces of my implementation will shine in the chat context: it escapes raw HTML, filters dangerous URLs, and bounds each message's work so a host can refuse an expensive one.

For trusted markdown source, some of those features are overkill.
