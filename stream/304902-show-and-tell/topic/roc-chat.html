Steve Howell (Nov 19 2026 at 18:15):

Unlike Zulip, which does HTTP long-polling for live updates, the roc-chat program uses SSE (server sent events). It's live-update system is home grown but mildly inspired by things like datastar and htmx. It's pretty ordinary JS on the client side operating on mostly HTML payloads.

Steve Howell (Nov 19 2026 at 18:37):

Unlike Zulip, which has a zillion dependencies, my server is very slim:

  • Zig: there's no build.zig.zon, so no Zig packages. The build links no system libraries, not even libc, and the deploy builds a static musl binary with Zig alone. Password hashing, HMAC, SHA-256, TLS for GitHub and the HTTP server all come from Zig's standard library.
  • Roc: the only package is roc-markdown (mine haha, see #show and tell > two roc-markdowns ), plus roc-chat's own platform.
  • JavaScript: the scripts in app/*.js import nothing and load nothing from another site. The page's security policy allows scripts from roc-chat's own origin only.

Caveats, outside the code:

  • Zig version: the box builds with my patched Zig (0.17.0+patched.2). I haven't checked whether roc-chat needs any of those patches or would build on a stock 0.17.
  • Running it: production also leans on Caddy (the proxy and TLS), systemd, ssh/scp for the deploy, and GitHub for OAuth. GitHub is optional: without the client files, there's no GitHub sign-in.
  • Developing it: the gate and tools need Shale (my scripting language) and git. tools/glue.shale also needs a checkout of Roc's source at the pinned commit.

It's the biggest Roc app I've written by 2x. The server piece in Roc is not the real challenge of writing a chat system, although it is important, so adversarial reviews would be helpful. A lot of the challenge for chat is product design (and I have my own taste on chat formed from a decade of using Zulip). All the visible pieces are more about JS choices than Roc choices. Roc would be more fun at scale, but chat communities don't challenge you on scale unless you make up problems that don't actually have to exist (cough Zulip cough).

For more details on the overall architecture see my Roc showcase page. Chat's at the top.
