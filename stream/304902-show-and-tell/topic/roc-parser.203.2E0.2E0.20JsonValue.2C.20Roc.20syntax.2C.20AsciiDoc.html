Another major release for roc-parser

https://github.com/lukewilliamboswell/roc-parser/releases/tag/3.0.0

  • new JsonValue for those extras builtin Json can't provide
  • new AsciiDoc parser matching the official Ruby implementation but a little faster
  • new RocSyntax for parsing .roc competitive perf with the official Zig :wink:
  • improved YAML source highlighting
  • Compile-time validation for YAML, XML, CSV, JSON, Markdown, AsciiDoc, HTTP, and Roc syntax

I've been using these to generate documentation, parsing SBOMs (SPDX and CycloneDX) and for syntax highlighting and it's really nice using pure Roc for these.
