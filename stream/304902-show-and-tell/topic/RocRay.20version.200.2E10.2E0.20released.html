Topic: RocRay version 0.10.0 released

Luke Boswell (Sep 28 2026 at 05:15):

Really big improvement with this next major version for RocRay :painting:

0.10.0 is the largest change to RocRay so far. The application model has been rebuilt: state changes and drawing are now separate callbacks, slow work runs as tasks without stalling the frame, and the platform gains files, HTTP, UDP, SQLite, subprocesses, screen capture and more

https://github.com/lukewilliamboswell/roc-ray/releases/tag/0.10.0

Big thank you to @Romain Lepert for working through lots of different issues and helping shape the APIs and bugfixes.

There is also now a large docs site with a tutorial and introduction to Roc -- which you can download as a PDF if you like. Would love you to check it out and let me know if you find it helpful.

https://lukewilliamboswell.github.io/roc-ray/
