pixelsprout (Nov 10 2026 at 08:57):

Thought I would share an experiment I have been working on making a simulation game for doing work with agents such as Claude or Codex. Essentially there is a relay server that runs and populates events emitted from agents doing tool calls large bodies of work, then the game is able to receive these events and update the state of the simulation.

We have a refinery that produces orbs (tickets), that then get picked up by otters (agents). The otters then work on their tasks within a workshop (repository). The orbs have colours that represent their state, such as white for ready and green for done.

This is a bit more fun and interesting for me then seeing a TUI all day :sweat_smile:
