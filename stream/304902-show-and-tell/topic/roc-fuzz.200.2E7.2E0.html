Topic: roc-fuzz 0.7.0

Luke Boswell (Nov 19 2026 at 00:15):

I dont normally announce every new release, but this one is important if you are using roc-fuzz as much as I am.

This new release enables you to combine many fuzz targets into a single binary, a fuzz suite. Instead of having a separate LLVM optimised build for each target you can now combine multiple into a much smaller set of binaries. This can dramatically reduce the build times in CI.
